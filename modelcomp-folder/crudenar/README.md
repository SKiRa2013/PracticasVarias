# Sistema CRUD Universitario CRUDENAR (Docker + PHP + AdminLTE)

Este proyecto es un sistema de gestión de estudiantes y facultades desarrollado con PHP, MySQL y la plantilla AdminLTE, diseñado para correr de forma aislada en contenedores Docker.

## 🚀 Instalación Rápida

1. **Requisitos:** Tener instalado [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. **Clonar/Descargar:** Descarga este repositorio en tu máquina.
3. **Levantar:** Abre una terminal en la carpeta raíz y ejecuta:
   ```bash
   docker-compose up -d --build
